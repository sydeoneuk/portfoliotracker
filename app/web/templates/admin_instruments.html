Force Metadata Refresh
Iterates every instrument and attempts to fetch fresh data from Yahoo Finance, FMP, and Claude. Existing values are only overwritten if new data is found — a lookup failure will never blank out data you already have. This may take several minutes.
Force T212 Data Reload
Re-fetches the Trading 212 instruments catalogue and updates base fields (name, ISIN, exchange, currency, type) for every instrument currently in the database — including stubs created from order/transaction history that may have missing data. Uses your T212 API credentials. Run this to fix instruments showing blank exchange or currency fields.
Load Full T212 Catalogue
Fetches every instrument available on Trading 212 (~16,000+) and inserts any that aren't already in the database. Existing rows are updated with the latest T212 base fields only — all enrichment data (sector, country, description, etc.) is preserved unchanged. Run this once to populate the Instruments research page, then the nightly sync will keep it up to date automatically.
OpenFIGI Enrichment
Looks up every instrument by ISIN (falling back to ticker) via the free Bloomberg OpenFIGI API. Populates FIGI, MIC exchange code, security type (Common Stock, ETP, Mutual Fund, etc.) and market sector. Fast — processes up to 100 ISINs per request in batches. Runs automatically at 04:00 UTC but can be triggered here to enrich the full catalogue on demand. No API key required for testing.
