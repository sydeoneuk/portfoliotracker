Clear Portfolio Data

Removes all synced positions, orders, transactions, dividend payments and pies for your account. Instrument metadata and dividend history are not affected. Your API keys and login are preserved. Run a sync afterwards to repopulate.

Delete Account

Permanently removes your account and all associated data — portfolio, dividends, transactions, orders, API keys and login. This cannot be undone and you will be logged out immediately.

⚠️ Clear All Portfolio Data?

This will permanently delete:

  • All positions
  • All orders
  • All transactions
  • All dividend payments
  • All pies and pie holdings

Instrument metadata, dividend history, and transactions are not affected. Your API keys and account login are preserved.

⚠️ Delete Account?

This will permanently and irreversibly delete:

  • Your login and identity
  • All API keys
  • All portfolio data — positions, orders, transactions, dividends, pies

There is no recovery. You will be logged out immediately.
